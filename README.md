# Batalha Naval
Jogo de Batalha Naval desenvolvido em C# como atividade proposta na faculdade.

## Linguagem
C#

## Passo-a-Passo
git clone https://github.com/Onuzb/BatalhaNaval.git
cd BatalhaNaval
dotnet run

## O que aprendi
Com esse jogo, aprendi os diversos formatos de mexer com as classes e funções, enfrentando desafios para enfim conseguir concluir o desafio.
